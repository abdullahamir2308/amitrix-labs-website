## Guardrails as code

[Placeholder] Each rule is a small, testable function:

```python title="guardrails.py"
from dataclasses import dataclass


@dataclass
class Decision:
    action: str
    confidence: float


def needs_human(decision: Decision, threshold: float = 0.85) -> bool:
    """Escalate low-confidence or high-impact decisions to a person."""
    high_impact = decision.action in {"cancel_order", "issue_refund"}
    return high_impact or decision.confidence < threshold
```
